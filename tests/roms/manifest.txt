#
#   path<TAB>source<TAB>pin<TAB>licence<TAB>sha256

#   path     the file's path from the repository root

#   pin      the upstream commit or release the file is taken from
#   licence  the licence that permits redistribution (SPDX identifier)
#   sha256   the file's SHA-256, 64 lowercase hex digits
#
# Lines starting with # are comments.
