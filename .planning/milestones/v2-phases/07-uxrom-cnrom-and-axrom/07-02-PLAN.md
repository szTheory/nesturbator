Any edge outside that table is unverified.
- The write path was checked during planning and is fixed: the PPU accepts `$2006`/`$2007` writes right after load, because `ppu.reset_flag` is set only by `nesturbator_reset` (`src/ppu.c` lines 613 and 621-625; `src/instance.c` line 172). Every PPU-memory write in this plan's cases goes through Plan 01's `ppu_poke` helper (`$2006` hi, `$2006` lo, `$2007` value on the CPU bus via `nesturbator__bus_write`). No case writes through `nesturbator__ppu_write`. Each negative or page-selection case is paired with a positive control that uses the same helper, so a PPU that ignored the writes would fail the control rather than let the negative case pass for nothing.
