## Decisions taken under Claude's discretion

- **Register round trip is whitebox:** the test writes register values directly into `inst->mapper.reg` and calls the board's rebuild, rather than building a CPU program per board; the CPU-driven path is covered by the fork matrix (Plans 04 and 05).
- **Mandatory op:** no NULL check in `src/state.c`; the table test makes a missing op a test failure, and the call would crash under ASan first.
