- **Header layout (discretion):** 64 bytes as in the truths above. `frame_number` and `ticks` sit in the header at offsets 32 and 40, not in a body section, so a host (and the runner in Plan 08) can read a state's position from the documented header without a fourth function; D-01 stays exactly three functions. - **Body order (discretion):** no tags (D-13): CORE (`cpu_cycle` u64, `audio_rem` u32, `profile.ane_magic`, `profile.lxa_magic`), CPU, BUS, APU, SYNTH, PPU, MAPPER (`irq`; Plan 02 appends the board op's registers after it), PRG-RAM (the whole `prg_ram_size` allocation), CHR-RAM (8192 bytes when `cart.chr_is_ram`). Each section follows the struct's field order.
- **header_size class (supersedes RESEARCH section 5, which classed it FORMAT):** D-03 defines FORMAT as bad magic or another format version only, and D-04 sends a flip anywhere outside magic, version, identity and the size field to CHECKSUM. So `header_size != 64` is checked after the CRC, in the INVALID stage.
- **Validation (RESEARCH Open Question 6, adopted with one change):** VALIDATE checks every range in RESEARCH section 3.1 to 3.4, plus the cross-field rules `ppu_ticks <= ticks` with `ticks - ppu_ticks < NESTURBATOR_TICKS_PER_FRAME` (replaces the probe's exact equality so that a state saved after `nesturbator_reset`, which runs 7 CPU cycles without catching the PPU up, still loads; it still bounds the PPU catch-up loop to under one frame, Pitfall P5), the synthesis sum invariant `integrator_q15 + sum(impulse) == mixed_level * 32768` (checked after the bounds), and `eval_copy_remaining != 0` requires `eval_count >= 1`. `ticks == 24 * cpu_cycle` and `cpu.p` are not validated. Plan 06 pins both sides of the `ppu_ticks` gap boundary.
- **Open Question 5 adopted:** `nesturbator_version` does not gain a format field; `NESTURBATOR_VERSION_SIZE_V1` and the 24-byte assertion stay.
- **Assumption delta:** the detector's "another game" signal is a false positive here. The cartridge identity (mapper, submapper, region, ROM CRC-32) stays the single identity noun; the phrase describes a test pre-fill. Decision `no-change`.
- **Reversibility:** D-01 one-way, D-03 one-way, D-13 one-way, D-08 costly. All four were chosen by the owner in CONTEXT.md, so ratings are recorded on Task 1 and no `checkpoint:decision` is added.
