## Decisions taken under Claude's discretion

- **Where the field bounds come from in the sweep:** the sweep must not keep a second hand-written copy of the field list that can drift. An internal test-only entry point in `src/state.c`, `nesturbator__state_bounds`, walks the visitor in a fifth mode and records `{offset, width, is_signed, lo, hi, cross}` for every bounded field (both bounds, so a signed field is swept below `lo` as well as above `hi`) and for each cross-field participant (`ppu_ticks`, `eval_count`, `eval_copy_remaining`, `mixed_level`, `impulse[]`, `integrator_q15`); declared in `src/internal.h`, so whitebox tests can call it; no public API change.
- **Stride under `--short`:** every header and body scalar byte is swept in both presets; PRG-RAM and CHR-RAM bytes (any value is legal there) are swept every byte in ci and with stride 97 under asan.
- **header_size (D-03, D-04):** checked in the INVALID stage per Plan 01, so the flip table puts bytes 10-11 in CHECKSUM and the version case covers only `format_version`.
