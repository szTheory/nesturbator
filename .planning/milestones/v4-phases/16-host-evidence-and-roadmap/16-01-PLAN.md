<interfaces>
Existing frame_index links nesturbator and nesturbator_host and uses bmp_ppm.c. Reuse nesturbator_test_read_ppm, nesturbator_test_read_bmp and nesturbator_host_convert; require 256 by 240 RGB pixels. Existing state APIs are nesturbator_state_size, nesturbator_save_state and nesturbator_load_state. The native header is 64 bytes, with format at 8, behavior revision at 16 and absolute frame at 32. The native loader deliberately does not enforce behavior revision.
New private CLI modes: frame_index --marker-generate ROM; --marker-qualify ROM CALIBRATION; --marker-observe ROM CALIBRATION IMAGE; --marker-anchor ROM CALIBRATION HOST_STATE EXPECTED_FRAME; --marker-selftest WORK. Existing ROM/W/image and --dups modes remain compatible.
Calibration records explicit first/last absolute frame, guest-to-absolute mapping, marker encoding version and current behavior revision. The hosted wrapper additionally binds SHA-256 of supplied/generated expected content, core and config. Do not trust a mutable calibration file to supply arbitrary accepted values; the tool checks it against its independently specified generator/qualification contract.
</interfaces>
