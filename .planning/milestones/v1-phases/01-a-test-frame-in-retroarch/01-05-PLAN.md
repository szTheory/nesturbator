4. `libretro/libretro.c` implements all 25 functions with the header's declarations, so RETRO_API exports them (Pattern 4). Behaviour:
   - `retro_api_version` returns RETRO_API_VERSION.
   - `retro_set_environment` stores the callback and calls SET_SUPPORT_NO_GAME (18) with a bool true.
   - `retro_init`/`retro_deinit`: deinit resets every adapter global, since the module can stay loaded (LIBRETRO-AND-RUNNER §1).
   - `retro_get_system_info`: library_name "nesturbator", library_version "MAJOR.MINOR.PATCH" built by stringising the header macros, valid_extensions "nes", need_fullpath false, block_extract false.
   - `retro_load_game`: info non-NULL → return false (D-10). info NULL → SET_PIXEL_FORMAT XRGB8888 (return false if refused), create the instance with NESTURBATOR_CONFIG_INIT, fetch the palette once with nesturbator_get_palette, return true.
   - `retro_get_system_av_info`: base and max 256x240, aspect_ratio 0.0f (width/height), fps = (double)fps_num / fps_den, sample_rate = (double)sample_rate_num / sample_rate_den, both from nesturbator_get_info. This is the only floating point, and it stays in the adapter (ENG.18).
   - `retro_run`:
     - input_poll once;
     - nesturbator_run_frame into a static uint16 buffer[256*240] and an int16 mono buffer[1024];
     - convert through nesturbator_host_convert into uint32 xrgb[256*240] (D-15);
     - video_cb(xrgb, 256, 240, 1024);
     - duplicate mono into an int16 stereo buffer[2048] and call audio_batch_cb once with audio_count frames.
     A non-OK status skips the callbacks except input_poll.
   - `retro_unload_game` destroys the instance. `retro_reset` does nothing for the static card.
   - `retro_get_region` returns 0 (NTSC); serialize_size returns 0; serialize/unserialize return false.
   - `retro_get_memory_data` returns NULL and `retro_get_memory_size` returns 0. The cheat, controller-port and load_game_special functions do nothing or return false.
   Comments cite libretro.h line numbers (L-numbers from LIBRETRO-AND-RUNNER §1).
