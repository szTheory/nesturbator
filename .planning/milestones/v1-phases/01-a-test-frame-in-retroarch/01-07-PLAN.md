Print offenders. The default allocator is chosen by plain code that assigns the static malloc/free wrapper functions into the instance at creation (plan 01; no file-scope allocator object), and a const lookup table holds integers only. A header comment in global_symbols.cmake states this rule and why.

     - it fails if the fixture builds and the symbol check passes.
