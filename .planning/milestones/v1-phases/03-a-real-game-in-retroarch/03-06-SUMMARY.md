# Phase 03 Plan 06: Licensed Game Hash Inventory

**Three pinned, redistributable mapper-0 games now have manifest SHA-256 pins and deterministic native frame hashes, including separate DABG port scripts and RHDE CHR-RAM startup.**

## Accomplishments

- Added Nesteroids (MIT), Double Action Blaster Guys (zlib), and RHDE (GNU All-Permissive / FSFAP) with exact source pins and artifact SHA-256 values in `tests/roms/manifest.txt`.
- Generated a sorted inventory of boot hashes at frames 1, 30, 60, 120, and 180, plus DABG port-0, port-1, and combined movie hashes at the same milestones. The inventory is 30 lines and is regenerated by the CI test.
- Confirmed RHDE iNES byte 5 is `00` (zero CHR-ROM banks). Its source README specifies 8 KiB CHR RAM; the project loader interprets this as CHR RAM.
- Audited the three selected games for LXA use. DABG's `lax` macro expands to `lda` and `ldx`; other `$AB` source occurrences are sound data, not executable LXA instructions. No selected game exercises LXA.
- Added a 32 KiB NROM reset-vector regression and fixed cartridge startup to read the vector from the end of PRG data. This was required for the real games to execute from their correct reset address.
