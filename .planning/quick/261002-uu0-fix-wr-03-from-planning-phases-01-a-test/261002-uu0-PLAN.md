<objective>
Close review finding WR-03 by adopting the caller-memset rule (owner decision, locked): every size-tagged struct is zeroed with memset by the caller before its fields are set, so padding and any bytes past an older library's struct are zero. Structs are NOT made padding-free; nesturbator_frame has interior padding next to its pointers whose layout differs between ILP32 and LP64.

Purpose: a host built against a newer header must not get a random NESTURBATOR_ERR_STRUCT_SIZE from an older library because of non-zero padding. The header promises its conventions are fixed, so this must be settled before the first release.
Output: header and README text, a frame size test, every in-repo caller following the rule, and the review ledger showing WR-03 fixed.
</objective>

- Size-tagged structs (first field uint32_t size): nesturbator_version, nesturbator_config, nesturbator_info, nesturbator_frame. nesturbator_allocator has no size field; it is a member of nesturbator_config and is zeroed with it.

No test covers a larger nesturbator_frame. The frame is the struct with interior padding, so the new test goes there.
