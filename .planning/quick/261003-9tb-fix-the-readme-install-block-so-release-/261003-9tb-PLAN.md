Release PR #2 failed CI because release-please's generic updater rewrites only the
first version on each line inside an x-release-please block. The README curl line
held the version twice (tag and file name), so the bump produced
`.../download/v0.1.0/nesturbator-0.0.0-libretro-macos-arm64.zip`.

Fix: put the version on its own line in the block (NESTURBATOR_VERSION=0.0.0) and
reference $NESTURBATOR_VERSION in the URL; teach check_install_line.cmake to resolve
it; add a ctest that fails if any marked line in any release-please extra-file holds
two versions; update README prose in the same change (project rule 6); run the ci
workflow; open the PR.

Output: fixed README block, updated install-line check, new ctest with self-test, open PR.
Do NOT merge any PR and do NOT touch PR #2.
