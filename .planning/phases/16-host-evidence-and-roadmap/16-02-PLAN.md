Define bounded evidence records in progression.h: calibration/content identity, monotonic boundary ID, logical operation kind, command/send counts, artifact identity, decoded absolute display frame, anchor identity/frame, effective display lead and intended relation. Parsing/identity, attribution, ambiguity, origin, progression, deadline and process failures have distinct stable reason codes. Success is exit 0 with a nonempty checked-boundaries count; semantic failure is exit 1 with a reason; usage/I/O/parse failure is exit 2. The prefix command validates exactly the declared completed prefix before the next driver mutation and emits PREFIX_OK, never whole-session success. The complete command requires every prescribed boundary plus terminal host exit; an incomplete prefix cannot be passed as a complete verdict. Both commands use the same production relation function. Private record serialization is versioned, length-bounded, rejects unknown/duplicate fields and preserves paths with spaces using explicit length or escaping. No path names or response text can become code.
</interfaces>
