## Decisions taken under Claude's discretion

- **Oversize reject seeds are bare 16-byte headers** (`mmc3-prg-1m`, `mmc3-prg-exp-huge`, `mmc3-chr-512k`): `board_profile_ok` runs before the total-size check (research section 1), so the header alone reaches the row; the matching `core.cartridge` row builds the full image in memory and carries the semantic proof. Every other seed is a full image.
- **Seed pin:** each manifest line uses `git rev-parse HEAD` at creation time, in the format of the existing seed lines.
- **Re-tagging (D-16):** research section 8 scanned every `NES\x1a` seed with the loader's NES 2.0 bit rule and found none decoding to mapper 4; Task 2 repeats the scan as a check and records the result in the summary.
