## Decisions taken under Claude's discretion

- **Derived entry form (D-02):** patches are written `set@10=07` and `or@6=02` (colons are the list separator). ROM entries name derived files as `derived/<key>.nes`; both list readers resolve that prefix to `<tests binary dir>/holymapperel/derived/`, i.e. `${NESTURBATOR_HM_DIR}/derived` in `tests/CMakeLists.txt` and `${BUILD}/tests/holymapperel/derived` in `write_hashes.cmake`.
- **Generation at build time, not in a ctest fixture:** CI runs `write_hashes.cmake` as a bare script after the workflow (research item 1), so the files must exist after any build.
- **Save-chain extension:** field 6 is the span size (`m4tkrom` uses 8192; `m1sxrom` keeps the default 32768 with no edit to its entry); field 7 adds one more `check_sav.cmake` run (`holymapperel.<key>.run1.sav_byte`) with the given offset and hex. `check_sav.cmake` already takes `SIZE`, `OFFSET` and `HEX`, so it is not edited.
