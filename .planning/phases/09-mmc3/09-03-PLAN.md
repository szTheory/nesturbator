## Decisions taken under Claude's discretion

- **Counting clocks:** tests write latch `$FF` with `$C000`, `$C001`, keep IRQ disabled, and read `nes->mapper.reg.mmc3.counter`: after the reload clock each later clock decrements by one, so the number of clocks in a span is the counter difference plus the reload. Per-line placement is checked by stepping to a dot before and after the expected edge, using the `start`/`step_to` style of `tests/ppu/test_fetch.c`.
- **Board writes** go through `nes->map.ops.cpu_write` with a stamp so the tests stay inside the PPU fixture; the IRQ path is already proven in Plan 01.
