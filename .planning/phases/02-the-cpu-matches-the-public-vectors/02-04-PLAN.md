  <action>
1. `tests/CMakeLists.txt`: add `function(nesturbator_vector_tests)`, taking a list of two-digit lowercase opcodes.
   - For each opcode it adds `cpu.vectors.<xx>`, which runs `cpu.vectors ${PROJECT_SOURCE_DIR}/tests/vectors/65x02-sample.n65v <xx> 256 100` through `tests/cmake/expect_output.cmake`, built the way `nesturbator_runner_test` builds it: COMMAND `${CMAKE_COMMAND}` with the quoted arguments `"-DCMD=${cmd}"` (cmd being `$<TARGET_FILE:cpu.vectors>` followed by the four arguments as a list), `"-DEXPECT=65x02/<xx>: 0 of 100 vectors failed"`, `"-DEXPECT_EXIT=0"`, then `-P "${CMAKE_CURRENT_SOURCE_DIR}/cmake/expect_output.cmake"`.
   - The script checks the exit status and the exact stdout, with carriage returns removed, so a reader error that exits 1 after printing `0 of 100 vectors failed` fails the test. The test's pass condition is that script's exit status alone: set no regular-expression property on it.
   - Each test gets `LABELS vectors`.
   - Call it with the LDA family and LDX zp,Y: `a1 a5 a9 ad b1 b5 b6 b9 bd`. `b6` is there so that `ea_zpy` has a caller.
2. `src/cpu.c`: add `static` effective-address helpers, each doing exactly the per-cycle table's accesses and returning the address (DEC.09, one bus call per cycle through the D-08 seam):
   - `ea_zp`, `ea_zpx`, `ea_zpy`, `ea_abs`;
   - `ea_absi(nes, idx, always_dummy)`, where the dummy read is at `(hi << 8) | ((lo + idx) & 0xFF)` on a cross, or always when always_dummy is set;
   - `ea_izx`, with the dummy read of the pointer and wrap within zero page;
   - `ea_izy(nes, always_dummy)`, with the pointer high byte from `(p + 1) & 0xFF`.
   Add the LDA cases above and `case 0xB6` (LDX zp,Y).
   - Every `static` helper this task adds has a caller among these nine cases: the presets build with warnings as errors and `-Wall` includes `-Wunused-function`, and C17 without extensions has no unused attribute. `ea_absi` and `ea_izy` are called with always_dummy 0 here; Task 2's stores pass 1.
3. Comments in `src/` use `0x` hex and words for section numbers (Pitfall 3). Shifts cast to `uint32_t` first (ENGINEERING section 1).
4. Run clang-format 18.
