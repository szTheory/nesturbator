Create `tests/ines.h` (include guard `NESTURBATOR_TESTS_INES_H`, includes `<stddef.h>`, `<stdint.h>`, `<string.h>`). Define `struct ines_spec` with the fields listed in "Artifacts this phase produces": `uint8_t prg_16k`, `uint8_t chr_8k` (0 means CHR RAM), `uint8_t mirroring_vertical`, `uint8_t nes2`, `uint16_t mapper`, `uint8_t submapper`, `const uint8_t *trainer` (512 bytes or NULL), `const uint8_t *prg_code` and `size_t prg_code_len` (copied at PRG offset 0, CPU `$8000`), `const uint8_t *chr_data` and `size_t chr_data_len`, and `uint16_t nmi_vector`, `reset_vector`, `irq_vector`. Add `static inline size_t ines_size(const struct ines_spec *s)` (16 + 512 if trainer + 16384 x prg_16k + 8192 x chr_8k) and `static inline size_t ines_build(uint8_t *out, size_t cap, const struct ines_spec *s)` that returns 0 when `s->prg_16k == 0`, `prg_code_len` exceeds PRG, `chr_data_len` exceeds CHR, or `cap < ines_size(s)`; otherwise zero-fills, writes `N E S 0x1A`, byte 4 = prg_16k, byte 5 = chr_8k, byte 6 = `(mapper & 0x0F) << 4 | (trainer ? 0x04 : 0) | (mirroring_vertical ? 0x01 : 0)`, byte 7 = `(mapper & 0xF0) | (nes2 ? 0x08 : 0)`, and when nes2 byte 8 = `(submapper << 4) | ((mapper >> 8) & 0x0F)`; then the trainer, PRG (code at offset 0, vectors in the last six PRG bytes as little-endian NMI, RESET, IRQ), CHR; returns the size. Every narrowing is an explicit cast (`-Wconversion -Wsign-conversion` are errors). Add a top comment citing the iNES and NES 2.0 header layout (NESdev Wiki "INES", "NES 2.0") and the loader's own `validate_image` as the authority for what is accepted today (mapper 0 only).

Unload the current game, build into `image`, load it with `p_load_game`, run one frame with `p_run`, check the captured frame's pixel (0,0) with `CHECK_EQ_HEX(frame[0], 0xBA3100u)`, write the image bytes to `rom_path`, run the runner through `test_process_run` with `--rom <rom_path> --frames 1 --dump-frame 1:<ppm_path>` exactly as `check_input_frame_parity` does, then call `compare_with_ppm(ppm_path)`. Call it from `main` right after `check_input_frame_parity(..., argv[4], argv[5], argv[3])`, passing the same `argv[4]`, `argv[5]`, `argv[3]`. Use a buffer large enough for `16 + 512 + 16384 + 8192` bytes (the existing `dummy_bytes` if large enough, else a local static array; check `ines_build` returned non-zero).
