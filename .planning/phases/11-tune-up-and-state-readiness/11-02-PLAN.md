## Decisions taken under Claude's discretion and orchestrator resolutions

- **C3 (D-08/D-09):** unload always runs the power-on helper, even with no cartridge; load never calls it.
- **Open question 3:** the library equality test goes in `tests/core/test_cartridge.c`, which already includes `src/` and builds synthetic images.
- **retro_init re-entry:** if `inst` is already non-NULL, `retro_init` destroys it first, then creates; cheap, and safe for a frontend that re-inits without deinit.
- **Order inside retro_load_game:** argument and pixel-format checks stay first, so a call rejected for a NULL data pointer or a refused pixel format changes nothing.
