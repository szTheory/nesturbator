## Decisions taken under Claude's discretion

- **D-20's unload confirmation is settled by measurement.** RESEARCH measured on the pinned 1.22.2 binary that a `--max-frames` exit runs `retro_unload_game` and writes `saves/game.srm` (log order: load_game, unload_game, deinit). The script asserts the file exists after session 1, so a change in that behaviour fails the job loudly.
- **The game-frame check and the save check stay separate invocations of one script.** The existing nesteroids comparison keeps its step unchanged. The save mode is a second step with `-DSAVE_ROM` and `-DSAVE_FRAME`, and both modes share `ra_session`.
- **Content stem:** the save mode copies the ROM as `content/M1_P512K_CR8K_S32K.nes`, so the `.srm` is `saves/M1_P512K_CR8K_S32K.srm` and the runner's `.sav` has the same stem.
- **Per-session file names** (`shot-<tag>.png`, `.bmp`, `runner-<tag>.ppm`) stop session 2 from reading session 1's screenshot (research Pitfall 11).
- **Recorded deviation from D-21's "pointer and size equal the direct API's":** the adapter owns its own instance inside the loaded module, and `abi.global_symbols` keeps the module's exports to `retro_*`, so the test program cannot call `nesturbator_get_memory` on the adapter's instance, and a second direct instance has its own allocation at another address. The check therefore reads D-21 as: the size equals the direct API's size for the same image; the pointer is non-NULL and keeps its address across `retro_run` and `retro_reset`; and after the same frames the adapter's span bytes equal the direct instance's span bytes (`memcmp`), which only holds if the adapter returns the instance's real span. The battery-less image checks NULL/0 on both sides. No export is added to make literal pointer equality testable (PROH-08-08-02, D-13).
- **The local RetroArch run is a development check, not an automated gate.** It needs a downloaded app and a logged-in GUI session, so Task 2's automated verify covers the script policy, hygiene and the CI wiring, and the two-session proof is the `retroarch-e2e` job that Task 3 gates on (nothing waits on a person).
- **`SAVE_FRAME`** is the pinned N of `m1sxrom` from `08-07-SUMMARY.md`, which is at least the frame where the result screen is static.
