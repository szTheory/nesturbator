## Decisions taken under Claude's discretion

- **Stamp fix in the tracer, not before it.** D-14 says the fix comes first among the MMC1 write-timing work. The tracer's first step is that fix, and its five-write CPU program is the first consumer of the corrected stamp, so the two prove each other.
- **Variant selection by sizes only** (D-10), with research C4: `ram_total <= 8 KiB` uses no bank bits, `16 KiB` uses `(chr0 >> 3) & 1`, and `32 KiB` uses `(chr0 >> 2) & 3`. The PRG outer bit is `(chr0 >> 4) & 1` only when PRG is above 256 KiB. SNROM disable applies when `chr_is_ram && prg_size <= 256 KiB && ram_total <= 8 KiB && (chr0 & 0x10)`. These conditions follow Holy Mapperel's `mmc1_test_wram_protection` expectations (research "Holy Mapperel screen and WRAM protocol").
- **CPU-level test cartridges** use `prg_16k = 2` (MMC1's 32 KiB minimum), with the reset vector in the fixed last bank and target bytes at `$8010`, never on a code byte (research Pattern 8).
