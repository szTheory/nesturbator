## Decisions taken under Claude's discretion and research adoptions

- **Open Question 2 adopted:** with `--save-dir`, the battery shadow and generation are captured before the state load (D-10 order), so a state with different battery bytes is written to the `.sav` at exit. Documented and tested (`save_dir` case).
- **Small modules (CLAUDE.md style):** the state file read lives in a new `runner/state_file.c` rather than growing `runner/main.c` (899 lines); writing reuses `nesturbator_run_file_replace`.
- **Corrupt fixtures:** CMake cannot recompute a CRC-32, so a small test tool `runner.state_mutate` (compiled with `src/crc32.c`) makes the truncated, flipped, version-changed and CRC-valid-but-invalid copies. No state file is committed (`*.state` is git-ignored and rejected by `scripts/hygiene.sh`).
- **Split with Plan 09:** this plan adds the two flags that move state in and out; Plan 09 adds `--hash-state`, the K range checks, the repetition rules for the same N, and the `--movie` and no-ROM refusals.

Create `runner/state_file.h`/`.c` with `int nesturbator_run_state_read(const char *path, uint8_t *buf, size_t cap, size_t *got)`: `stat` the path first (POSIX `stat`/`S_ISDIR`, Windows `_stat`/`_S_IFDIR`, the same split as `runner/save.c`) and treat a directory as a read failure; `fopen(path, "rb")`; `fread` up to `cap` bytes; on any failure print `nesturbator-run: cannot read state <path> (<strerror>)` and return 1; else return 0 with `*got`.
