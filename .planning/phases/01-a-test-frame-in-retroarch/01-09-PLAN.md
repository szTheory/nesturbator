<objective>
Build the RetroArch comparison of FRAME-05. It has two parts:
- a portable, bounds-checked frame comparator, tested on every platform with synthesised images;
- a macOS `cmake -P` driver that launches RetroArch unattended in an isolated configuration, converts its screenshot with `sips`, and requires exact equality with the runner's frame. Where RetroArch is absent the driver reports itself skipped.

  <behavior>
    - P6 reader: accepts "P6", whitespace, "256 240", whitespace, "255", one whitespace byte, then 184320 bytes. It rejects any other width, height or maxval and short data.
    - BMP reader: "BM" magic; little-endian fields read byte-wise. Header size must be 40, 108 or 124. bpp 24 with compression 0, or bpp 32 with compression 0 or 3. For compression 3, masks come from file offset 54 and are mapped by shift. Height negative means top-down, positive means bottom-up. Stride is ((w*bpp+31)/32)*4. It rejects data offset + stride*|h| > file size, width or |height| of 0, and any field read past the end.
    - Comparison: both 256x240 or exit 1 with "size W x H, expected 256 x 240". The first differing pixel is printed as "first difference at X,Y: expected RRGGBB got RRGGBB".
    - The variants and negatives listed in must_haves truths 2–5.
  </behavior>
  <action>

   - `int nesturbator_test_read_ppm(const char *path, uint8_t rgb[256*240*3])`;

   - `int nesturbator_test_compare(const uint8_t *a, const uint8_t *b, uint32_t *x, uint32_t *y)`.
   Return codes: 0 ok, 1 mismatch or size, 2 parse error. Plain C17; fopen "rb"; `_CRT_SECURE_NO_WARNINGS` on MSVC.
