Create tests/cmake/perf_compare.cmake (first line `cmake_minimum_required(VERSION 3.25)`; a header comment stating inputs, the formula and the status words). Inputs: MODE (report or gate, required), DIR (required), ALLOW (required path), LABEL (the name printed for the allow file, default `tests/perf/allow.txt`), OUT (Markdown output path, required), TODAY (YYYY-MM-DD; default `string(TIMESTAMP ... "%Y-%m-%d" UTC)`), BASE_SHA and HEAD_SHA (each must match `^[0-9a-f]{40}$` or be empty, printed as `n/a` when empty), VALGRIND_VERSION and GCC_VERSION (each must match `^[A-Za-z0-9 ._()+:~-]*$`, else the script fails with `unsafe version text`). The ROM list is fixed in the script, in order: nesteroids mapper 0, runner mapper 1, M4_P256K_C256K mapper 4 (D-09). For each ROM and each of base_a, base_b, head read `${DIR}/<who>_<rom>_60.out` and `_360.out`; a side is present only if both files exist and each has exactly one `summary:` line matching `^summary: *([0-9]+)$` (copy CMAKE_MATCH_1 into a variable at once). d = Ir360 - Ir60 with math(EXPR); a d of 0 or below is treated as missing.

Verdict per ROM: base_a and base_b both present and unequal gives status UNSTABLE (the script also prints `UNSTABLE: <rom> base_a <d> base_b <d>` and remembers to exit non-zero in every mode, D-11). Missing sides follow D-10 and D-14 (orchestrator decision): a base that is missing (either base measurement absent, because the base did not build or run) gives n/a in both modes and never fails the job; a missing head gives n/a in report mode and FAIL with `missing head for <rom>` in gate mode. UNSTABLE still fails whenever both base measurements exist and differ. Otherwise delta = d_head - d_base and the ROM FAILs when `delta * 100 > d_base` (D-14) unless an allow entry covers it (Task 2), else ok. The table (D-12) is written to OUT: header `| ROM | mapper | base Ir/frame | head Ir/frame | delta Ir/frame | delta % | status |`, then one row per ROM `| <rom> | <mapper> | <d_base/300> | <d_head/300> | <signed delta/300> | <signed pct>% | <status> |` where pct is computed only for display as pct_x100 = |delta| * 10000 / d_base with the sign prefixed (`+0.00` for zero) and printed with two decimals by integer division; n/a cells print `n/a`. Footer lines: `base <BASE_SHA> head <HEAD_SHA>`, `valgrind: <VALGRIND_VERSION>`, `gcc: <GCC_VERSION>`, and the formula `Ir/frame = (Ir(360) - Ir(60)) / 300; FAIL when (d_head - d_base) * 100 > d_base`. Also print the same text with message(STATUS) so it shows in logs. Exit: FATAL_ERROR (non-zero) on UNSTABLE in any mode; in gate mode on any FAIL (`perf gate: <rom> +<pct>% exceeds +1.00%`); in report mode exit 0 for FAIL and n/a rows.
