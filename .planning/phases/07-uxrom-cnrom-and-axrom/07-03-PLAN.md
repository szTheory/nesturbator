## Edge classification (BOARD-01)

The fallback edge probe returned BOARD-01 as `unclassified`. These are the categories that apply, classified by hand, each mapped to a named test case in this phase.

| Category | BOARD-01 edge | Named test case (plan) |
|---|---|---|
| Boundary (size limits) | UxROM PRG at 4 MiB accepted, 4 MiB + 16 KiB refused | `test_board_profiles` rows `uxrom-4mib`, `uxrom-4mib-plus-16k` (03) |
| Boundary (size limits) | CNROM CHR 8/16/32 KiB accepted, 64 KiB refused; PRG 64 KiB refused | rows `cnrom-chr-1/2/4`, `cnrom-chr-64k`, `cnrom-prg-64k` (03) |
| Boundary (size limits) | AxROM PRG 32-256 KiB accepted; 16, 48 and 512 KiB refused | rows `axrom-1/2/4/8`, `axrom-prg-16k`, `axrom-prg-48k`, `axrom-512k` (03) |
| Boundary (enumerations) | submapper 2 accepted, 3 refused; mapper ids 256 and 4095 (both ends of "256 or above") refused; ids 0-4095 walked | rows `*-sub2`, `*-sub3`, `nes2-mapper-256`, `nes2-mapper-4095`; `test_board_switch_matches_profiles` (03) |
| Wrap / overflow | register value past the bank count wraps by modulo | `uxrom_fixed_last_bank_and_wrap` (01), `cnrom_chr_size_and_wrap`, `axrom_prg_wrap` (02) |
| Adjacency (address) | a write to `$7FFF` does not bank, a write to `$FFFF` does | `uxrom_write_boundary` (01), `cnrom_write_boundary` (02) |
| Adjacency (fixed vs switched window) | UxROM `$C000` stays on the last bank | `uxrom_fixed_last_bank_and_wrap` (01) |
| Ordering | AND uses the PRG byte mapped before the write | `uxrom_and_against_pre_write_bank` (01), `axrom_and_submapper2` (02) |
| Ordering | board probed before allocation; PC read after the board builds its pages | `test_unboarded_id_leaves_instance` (01), `axrom_power_on_pc` (02) |
| Initial state | every register 0 at power-on | `uxrom_power_on` (01), `cnrom_power_on`, `board_power_on_registers` (02) |
| Empty / NULL | CHR-ROM write page is NULL so the write is dropped; CHR-RAM page writes | `cnrom_chr_rom_write_dropped` with its positive control `chr_ram_write_lands_control`, which uses the same `$2006`/`$2007` path on a CHR-RAM image (02); `uxrom_chr_ram_write_sticks` (01) |
| Conflicting input | AxROM ignores the header mirroring bit; four-screen and battery refused | `axrom_ignores_header_mirroring` (02); rows `*-four-screen`, `*-battery` (03) |
| Malformed input | trailing or missing byte, DiskDude, PRG-RAM | rows `*-trailing`, `*-truncated`, `diskdude`, `prg-ram` (03); seeds `cnrom-chr-ram`, `axrom-odd-prg`, `submapper-3` (03) |
