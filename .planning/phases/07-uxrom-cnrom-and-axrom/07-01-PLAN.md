## Decisions taken under Claude's discretion

- **D-10 as implemented (no departure):** D-10 requires both that `nesturbator__mapper_load` fail when no board matches and that the load return `ERR_CARTRIDGE` with the instance untouched. The second half cannot hold if the lookup first happens at the end of the load, because the old cartridge is freed and every subsystem reset by then (research Pitfall 2). So the single switch moves into `nesturbator__mapper_ops_for`, which `validate_image` calls with a scratch ops struct before any allocation, and `nesturbator__mapper_load` calls again and returns 0 on no match. This also closes Phase 6 review finding IN-01 (unknown id loads as an empty cartridge); record that in the SUMMARY.
- **Why the tracer is the loader path, on NROM:** the riskiest change in the phase is the load order (probe before allocation, PC after the board builds its pages). Task 1 proves it end to end on the board that already exists, with every pinned NROM hash as the oracle. It also rewords `libretro/libretro.c` line 5 so that it names no board ("cartridge content"), which is true before and after every later board; so no board task needs to touch the adapter and every board task stays under ten files while carrying its own wording (CLAUDE.md rule 6).
- **Docs move with each board:** Task 2 names mappers 0 and 2; Plan 02 adds 3, then 7, in the task that adds each board. At every commit the docs name exactly the boards that load.
- **D-14 shared helper placement:** the helpers are `static inline` in `src/internal.h`, next to `nesturbator__map_prg`/`_chr`, following Phase 6's precedent (no `src/mapper.c`, no new symbol for `abi.global_symbols`). Besides D-14's mirroring helper, two more cover the `$6000` trainer-RAM pages (research Pitfall 9) and the 8 KiB CHR bank, so all four boards share them.
- **D-09 byte-7 rule:** mappers 2, 3 and 7 have a zero byte-7 high nibble, so the `(image[7] & 0xf0u) != 0u` rejection in `validate_image` stays exactly as it is (research Pitfall 4); D-09's "relaxed only so that 2, 3 and 7 pass" is satisfied without editing it.
- **D-15 per board:** each board's `init` evaluates D-15's predicate for its own id (UxROM: AND when submapper is 0 or 2), so no board reads the id.
- **`init` does not zero registers:** registers are zero because the loader `memset`s `inst->mapper` before setting id and submapper; `nesturbator__mapper_load` is also the future state-load path, so `init` only sets `map.watch`.
- **Test byte layout:** each 16 KiB PRG bank b carries marker `0x10 + b` at bank offset `0x0010` and an AND seed at bank offset `0x0000`, so a write to `$8000` ANDs with the seed and `$8010` identifies the bank.
- **Commit shape:** every task's verify keeps the touched subset green; Plan 04's last task runs every preset and pushes.
