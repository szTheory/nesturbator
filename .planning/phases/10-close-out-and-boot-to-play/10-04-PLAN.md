    - boundary pairs and the adjacency, empty and ordering cases from this plan's edges: exact masks.

  <action>
Per D-12 and D-13. Build every case with the Task 1 helper; no emulation. Constant tone: loud peak-to-peak but every window hash equal. Click then silence: first window loud, the rest zero. Static picture with ticking counter: positive RAM and score, all pixel-change counts zero and frames equal to N's. Rainbow-only title: N's trace with pixel changes of 735. NMI-alive hang: N's RAM ($3E 0) with the positive audio. Early death: positive trace with `$3E` 3 and the score frozen from checkpoint 300. Input latched late (CONTEXT specifics, D-12, D-13): a helper `set_first_divergence(trace, n, frame)` copies N's RAM digest into the positive trace for every frame before `frame` and, if the digest at `frame` equals N's, XORs it with 1; the mutant uses `frame = START_FRAME + LATCH_SLACK + 1u` and is asserted with `CHECK_EQ_U64` to be exactly P1, since no other field changes. The same helper builds the latch boundary pair: `START_FRAME + LATCH_SLACK` gives 0 and `START_FRAME + LATCH_SLACK + 1u` gives P1. These cases add no threshold change; the four control masks from Plan 03 stay exactly as asserted there (none's missing divergence maps to P1, already in its mask). Boundary pairs, each built from the positive trace by one construction rule. The rule changes the threshold field and every field coupled to it, so all other P1, P2 and P3 sub-checks still hold. Each pair is asserted with `CHECK_EQ_U64`: exactly its one bit on the failing side and 0 on the passing side.
(a) K pair (35/36): a helper `set_score_ladder(trace, final)` overwrites the score at every checkpoint c from 150 to 600 with `final - (600 - c) / 30u`. Changing only the final score would break the 60-frame ordering, because the real f540 score is 45. The ladder rises by 2 every 60 frames, so `score(c) > score(c - 60)` holds for c from 210 to 600. With `final = K_SCORE - 1u` the mask is P1; with `final = K_SCORE` it is 0. Add a `_Static_assert` that `K_SCORE >= 16u` so the ladder cannot underflow at c = 150.
(b) F pair (4095/4096): set the changed-pixel count of the one window ending at f390 to `F_PIXELS - 1u` or `F_PIXELS`. The stored frames at 300 and 600 are not touched, so the A/B check is unaffected. Mask P2, or 0.
(c) Audio floor (2047/2048): set the peak-to-peak of the window ending at f390 to `AUDIO_FLOOR - 1` or `AUDIO_FLOOR`. Its hash is not touched. Mask P3, or 0.
(d) A/B share (30719/30720): replace the stored frame 300 with N's frame 300 in which the first m pixels are XORed with 0x01; this changes each one and keeps it a valid 9-bit pixel. Use m = 61440 / 2 - 1 (P2) or m = 61440 / 2 (0), derived from the 50% share expression `judge` uses. Frame 600 and the changed-pixel counts are not touched.
(e) Window share (11/16, 12/16): copy N's window hash into the positive trace for the windows ending at f480, f510, f540, f570 and f600 (five copies, 11 of 16 differ, P3), or for the last four (12 of 16 differ, 0). N's windows are pairwise distinct (10-RESEARCH.md "Audio"), so the copies keep the trace's windows pairwise distinct. Peak-to-peak values are not touched.
Also add the plateau pair. The 30-frame plateau ladder `score(c) = 52u - (600u - c) / 60u` gives mask 0. The positive trace with the f510 score set to the f450 score (37) gives mask P1; f540 and f570 stay above it. Add the zero-frame and 599-frame traces (mask P1|P2|P3). Add the time-shifted RAM trace: the frame-60 RAM digest is set to N's frame-60 digest XOR 1 while the first input frame stays 61, giving mask P1. Each is asserted with its exact mask. Derive each boundary value from the named `#define` (for example `K_SCORE - 1u`), not a second literal, so a moved threshold moves its pair. If a case gets the wrong mask, fix the judge defect it reveals without moving a threshold (PROH-10-04-02) and record it in the SUMMARY.
