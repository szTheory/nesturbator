## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Hosted-only literal goes stale | run_retroarch.cmake hardcoded `revision=6`; only the hosted retroarch-e2e job ran it, so the bump to 7 broke CI only | advisory | Derive values from `include/nesturbator.h`; `retroarch.revision_literals` test rejects literals |
| Fingerprinted file reformatted | Formatting runner/accuracycoin.c or tests/accuracy/test_conformance.c changes build_inputs_sha256 and fails accuracycoin.activation | advisory | Rerun the full AccuracyCoin campaign and re-record tests/accuracy/baseline-metadata.txt in the same change |
| `gh pr checks --required --watch` exits early | Returns "no required checks reported" before the CI required job exists | advisory | Watch the CI run (`gh run watch <id>`) instead |
